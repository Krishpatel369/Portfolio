# Krish Ghodasara | Portfolio

Personal portfolio website of **Krish Ghodasara**, a MERN stack developer from Ahmedabad, Gujarat, India, who is also learning DevOps.

## Features

- Single-page layout with a sticky identity column and scrolling sections
- Sections: About, Skills, Experience, Projects, Education, Resume and Contact
- Dark theme by default, with a light theme toggle that remembers your choice
- Fully responsive, from phones to large desktops
- Resume download (PDF)
- Copy-to-clipboard buttons for email and phone
- Hover and tap effects, with support for reduced motion
- No frameworks or build step: just HTML, CSS and JavaScript

## Project structure

```
portfolio/
├── index.html                    # Page structure and content
├── style.css                     # Styling, themes and responsive layout
├── script.js                     # Theme toggle and copy buttons
├── Krish_Ghodasara_Resume.pdf    # Resume used by the download button
```

## Run locally

No installation is needed.

1. Download or clone this repository.
2. Open `index.html` in your browser.

Or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Push these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Customize

- **Content:** edit the text in `index.html`.
- **Colors and fonts:** change the CSS variables at the top of `style.css`.
- **Resume:** replace `Krish_Ghodasara_Resume.pdf` with a new file of the same name.
